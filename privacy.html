Privacy

Privacy claims are separated by surface, not flattened into a blanket promise.

AgentReady Community is local-first for current browser and CLI scans, but this page avoids universal zero-data-collection claims because website hosting, npm, GitHub and future Pro surfaces have different data flows.

Website

Browser scanner

The current scanner pages analyze selected files in the browser and do not require uploading the selected OpenAPI or MCP file to a TimeProofs backend. Static examples may load public fixture files from the site.

CLI and npm

The CLI reads local files and writes local report outputs. npm package downloads and public registry metadata are handled by npm, not by a TimeProofs account system.

GitHub Action

The Action runs inside the consumer repository workflow and reads files available in that workflow. GitHub workflow logs, artifacts and repository visibility are governed by the consumer repository configuration.

Voluntary feedback

Feedback, pilot reports or public issues are voluntary and should not include secrets or confidential contracts unless the owner deliberately chooses to disclose them.

Planned Pro

AgentReady Pro is planned and not purchasable. Account, billing, entitlement, support and hosted-service data flows must be documented before those surfaces become available.

Cookies and analytics

The current static Community scanner does not require advertising cookies or analytics cookies to perform a scan. This batch adds no analytics tracker, telemetry system, account system, billing system or hosted scanner.

Contact and rights

Privacy requests may be sent to contact@certif-scope.com. Legal bases, recipients and retention periods are not generalized on this page where the current repository or owner review does not support an exact statement.

Mandatory limitation

TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

AgentReady at a glance

AgentReady privacy varies by surface: browser scans are local, CLI reads local files, GitHub Actions run in workflows, and hosting logs may exist. AgentReady is a product and candidate open standard for static pre-deployment analysis. It is not a runtime firewall, independent certification, official standards-body standard or guaranteed-safety system.

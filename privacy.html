Privacy policy

How TimeProofs AgentReady handles files and personal data. Last updated: 2026-06-30.

Local-first file analysis

TimeProofs AgentReady Browser V1 is designed to analyze OpenAPI, MCP tools, agentready.json, and simulation scenario files locally in the browser.

The static scanner pages do not need to upload selected files to a TimeProofs backend to perform a scan.

No account, payment, or dashboard in Browser V1

The current Browser V1 surface does not include accounts, user dashboards, payment flows, or a database.

Static fixtures and assets

Some example buttons may load static JSON fixtures from the website, such as OpenAPI examples, MCP examples, or simulation scenarios. These are public example files used to demonstrate the product.

Hosting and technical logs

When the site is visited, the hosting provider may process standard technical access logs, such as IP address, user agent, requested URL, timestamp, and technical error data. These logs are generally used for security, performance, reliability, and abuse prevention.

Production hosting provider details and retention information must be confirmed before public launch.

Cookies and analytics

The current static product surface does not require advertising cookies or analytics cookies to perform a scan.

If analytics, support tools, payment providers, account systems, or other third-party services are added later, this policy must be updated before public launch.

Sensitive files

Even though Browser V1 is designed for local analysis, users should avoid using sensitive, confidential, secret, production, or regulated files unless they understand the environment in which they are testing the site.

Users remain responsible for reviewing their own OpenAPI specs, MCP tool definitions, credentials, URLs, and examples before using them in any tool.

Contact and rights

Contact details for privacy requests must be completed before a public production launch.

This page is a practical pre-release draft and should be reviewed before adding accounts, payments, analytics, support, or a hosted backend.

TimeProofs AgentReady

Static readiness gate for agent-facing OpenAPI and MCP contracts. TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

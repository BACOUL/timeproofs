# TimeProofs V2 security

TimeProofs V2 is a reference alpha. Do not submit private production evidence to the public sandbox preview. SATISFIED means the declared requirements pass under a specific profile and verifier-owned trust policy; it does not establish truth, legality, compliance or legal admissibility.

The [threat model and release checklist](docs/security.md) describe implemented controls, key rotation and revocation, replay boundaries and production gaps. The [verification record](docs/verification.md) distinguishes verified capabilities from pending acceptance checks.

Security documentation and reports are maintained in English. For sensitive vulnerability reports, use GitHub private vulnerability reporting if it is enabled for this repository; otherwise request a private reporting channel from the maintainer before disclosing details. Do not publish credentials, private keys or exploitable sensitive data in a public issue. No response-time SLA is currently offered.

What is real today

The public repository exposes source, documentation, issues and pull requests through GitHub. Community usage does not require a TimeProofs account. Rule changes and governance decisions require recorded project change control.

What is not promised

No response time, support SLA, guaranteed fix, contributor acceptance, partnership program, security bounty, certification route or standards-body membership is currently promised by these pages.

NeedCurrent factual pathBoundary

TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

AgentReady at a glance

Current contribution paths are GitHub Issues for reproducible problems and pull requests for concrete changes; no SLA or standards-body process is promised. AgentReady is a product and candidate open standard for static pre-deployment analysis. It is not a runtime firewall, independent certification, official standards-body standard or guaranteed-safety system.

Availability
AgentReady Community is free and available. AgentReady Pro is planned and not purchasable.
Language
English is the current canonical language. No translated alternate route is published for this page.

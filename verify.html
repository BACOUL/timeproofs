Create & Verify a Proof

One place to create and verify TimeProofs. Your browser computes the hash locally, the API returns a signed .tproof.json bundle you can download, share, or inspect offline. Your content never leaves your device.

Verify by URL

GET https://api.timeproofs.io/api/verify?hash=<SHA256-hex>
Accept: application/json

Example

curl -sS "https://api.timeproofs.io/api/verify?hash=7c040f8633b8..." \
  -H "Accept: application/json"

You can also share /verify.html?hash=<hash> as a public verify link.

Create (POST /timestamp)

POST https://api.timeproofs.io/api/timestamp
Content-Type: application/json
Accept: application/json

{
  "hash": "sha256-hex",
  "type": "event",
  "meta": { "source": "web" }
}

Verify (GET or POST /verify)

GET  https://api.timeproofs.io/api/verify?hash=sha256-hex
POST https://api.timeproofs.io/api/verify
{ "hash": "sha256-hex" }

Quick FAQ

Is my content stored?
No. Only the hash circulates. The original content never leaves your device.

Why no blockchain?
To keep latency low (<100 ms), costs predictable, and verification simple.

Offline verify?
You can download a .tproof.json bundle and inspect it offline (hash, timestamp, signatures) and re-check it at any time via the public API.

Compliance?
Privacy-first, hash-only. See Regulations & Compliance.

Create & Verify a Proof

Hash locally → timestamp & sign via API → verify publicly. Your content never leaves your device. Max file size: 50 MB.

How this tool works

  1. Create — Type text or pick a file. The fingerprint (SHA-256 hash) is computed locally. We never receive your content.
  2. Timestamp — Press Timestamp. You get a signed receipt with the hash and the time.
  3. Prove — Share the Verify result or download a .tproof.json bundle to keep with your file.
  4. Verify — Anyone can check the hash later. If the hash matches, existence at that time and integrity are proven.

No blockchain. Hash-only. Public verification. See Regulations for compliance.

URL checks (GET)

Simple verification via query string. JSON responses.

Verify by URL

GET https://api.timeproofs.io/api/verify?hash=<SHA256-hex>
Accept: application/json

Example

curl -sS "https://api.timeproofs.io/api/verify?hash=7c040f8633b8..." \
  -H "Accept: application/json"

Tip: you can share /verify.html?hash=<hash> for a public verification link.

Bundle .tproof.json

A portable file that contains the proof, not the content. Easy to share and verify anywhere.

Schema

{
  "version": "v0.1",
  "hash": "sha256-hex",
  "algorithm": "SHA-256",
  "timestamp": "2025-11-04T10:22:33.123Z",
  "signature": "base64/hex",
  "signer": "TimeProofs",
  "meta": { "source": "web:verify", "filename": "optional" }
}

Create the bundle client-side

const bundle = {
  version: "v0.1",
  hash: proof.hash,
  algorithm: "SHA-256",
  timestamp: proof.timestamp,
  signature: proof.signature,
  signer: "TimeProofs",
  meta: proof.meta || {}
};
// JSON.stringify(bundle) then save as .tproof.json

The Download .tproof.json button uses the latest response from “Create”.

Quick FAQ

Is my content stored?
No. Only the hash is exchanged. Your content stays local.

Why no blockchain?
Latency <100 ms, predictable cost, simple public verification.

Offline verify?
v0.1: API verification. v0.2: offline/bundle mode planned.

Privacy & regulations?
Privacy-by-design, hash-only. See Regulations & Compliance.

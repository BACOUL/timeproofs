Verify a proof

To verify a TimeProofs record, you use two files: the .tproof.json proof file and (optionally) the original file to check “same version”.

The proof file is required. The original file is optional and is hashed locally in your browser.

Proof verifier

1) Load the .tproof.json proof file • 2) Verify the proof signature • 3) (Optional) load the original file to check if it matches the frozen version.

Simple meaning: TimeProofs does not lock or protect your file. It proves that a specific version existed at a specific time.
To check a version, we compare the file’s SHA-256 to the hash inside the proof.

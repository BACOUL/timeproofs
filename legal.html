2. Definitions

  • Service: the websites, official APIs, SDK/CLI, offline/local tools, and any hosted UI operated under the timeproofs.io domain or subdomains.
  • Hash: irreversible SHA-256 digest (or other supported algorithm) of input content.
  • Proof: tuple (hash, ts, sig, optional meta) that attests that a given hash existed at a specific time and was signed by TimeProofs.
  • Bundle (.tproof.json): structured JSON document containing a proof plus protocol metadata (for example: version, hash, algorithm, timestamp, signature, signer, meta).
  • Meta: optional small JSON you provide. It MUST NOT contain personal data or sensitive information.
  • Offline tools: SDK/CLI/verify UIs capable of creating or verifying proofs without sending original content to TimeProofs servers.

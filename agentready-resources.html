Governance and namespace

The current official namespace is AR001, AR002 and onward. Rule changes require recorded review and change control. Community, research and vendor namespaces may be introduced separately without changing the official AR namespace.

Contribution paths are limited to real repository capabilities: issues, pull requests and documented review by the project owner. This page does not create a foundation, committee, formal standards organization or certification authority.

Reference implementation

Community users can run the current static scanner in the browser, npm CLI or GitHub Action. These are distribution paths for the reference implementation, not separate rule systems.

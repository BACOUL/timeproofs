/* PRODUCT */
Direction: Pre-deployment CI gate for agent-facing OpenAPI and MCP tools.
Purpose: Find risky OpenAPI and MCP tool contracts before AI agents use them.
Outputs: AgentReady Score, risk findings, Markdown report, agentready.json, agentready-simulation.json.

/* BOUNDARIES */
Static scanner.
Local/browser-first product surface.
No live API execution.
No live MCP execution.
No LLM call.
No runtime firewall.
No dashboard, Stripe, account system, or backend in Browser V1.

/* LEGACY */
The old proof/timestamp/verify/ProofSpec direction is legacy context and is not the active product direction.

/* LIMITATION */
TimeProofs AgentReady does not guarantee that an AI agent will never fail.
It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

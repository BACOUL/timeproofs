Terms of use

Terms for using TimeProofs AgentReady Browser V1. Last updated: 2026-06-30.

Pre-release product

TimeProofs AgentReady Browser V1 is under validation. It should not be treated as a complete public release until the Browser V1 release gate is passed.

Purpose of the tool

The scanner helps identify structural readiness risks in OpenAPI specs, MCP tool definitions, and static simulation scenarios before exposing tools to AI agents.

It is a static analysis and reporting tool. It does not execute API endpoints, MCP tools, LLM prompts, or agent actions.

No safety guarantee

TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

User responsibility

Users remain responsible for reviewing outputs, validating recommendations, testing their systems, and applying appropriate security, authorization, privacy, logging, monitoring, and human-confirmation controls.

Users should review files before testing them and should not rely on AgentReady as the only control before exposing high-risk tools to AI agents.

No professional advice or certification

Reports generated by AgentReady are technical readiness aids. They are not legal advice, security certification, compliance certification, audit certification, or professional assurance.

Acceptable use

Do not use TimeProofs AgentReady to test files or systems that you are not authorized to evaluate. Do not attempt to use the site to attack, overload, or interfere with third-party services.

Availability and changes

Browser V1 may change during validation. Pages, examples, report formats, scoring rules, and exported JSON contracts may evolve before a final public release.

Final review required

These terms are a practical pre-release draft. They should be reviewed and completed before production launch, especially if accounts, payments, analytics, support, hosted storage, or paid reports are added.

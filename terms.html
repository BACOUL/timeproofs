Purpose

AgentReady helps identify structural readiness risks in OpenAPI specs and MCP tool definitions before exposing tools to AI agents. It does not execute API endpoints, MCP tools, LLM prompts or agent actions.

User responsibility

Users remain responsible for reviewing outputs, validating recommendations, testing their systems and applying security, authorization, monitoring, logging and human-confirmation controls.

Community package boundary

The npm package boundary for AgentReady Community is Apache-2.0. The root repository license history and future Pro components remain separate as documented in Community license decisions.

Planned commercial surfaces

AgentReady Pro is in preparation and unavailable for purchase. Billing, accounts, entitlement, support and legal terms must be completed before any Pro purchase flow exists.

No professional assurance

AgentReady reports are technical readiness aids. They are not legal advice, security certification, compliance certification, audit certification, professional assurance or a guarantee that an AI agent will never fail.

Mandatory limitation

TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

Protocol — ProofSpec

Open specification to prove when data existed and that it has not changed. Hash-only inputs, signed timestamps, public verification.

Overview

ProofSpec defines a minimal, interoperable tuple for proof of existence. Implementations MUST NOT upload original content. All verification steps are public and deterministic.

  • Input: SHA-256 of caller-provided bytes.
  • Output: signed tuple and a stable public verification URL.
  • Privacy: original content never leaves the device.

Canonicalization & hashing

  • Input: raw bytes. No normalization.
  • Text: encode as UTF-8 without BOM before SHA-256.
  • Hash: lowercase hex, 64 chars.
  • Timestamp ts: integer epoch milliseconds UTC.
  • Signed message: ASCII hash|ts (no spaces).

Proof format

{
  "hash": "7c040f8633b8823d72ed63da9b3b2dfe9846e912c66a64c9433ec9c4815d76c2",
  "ts": 1730793600000,
  "sig": "base64url(HMAC_SHA256('hash|ts', key))",
  "meta": {"source":"web"},
  "verify_url": "https://api.timeproofs.io/api/verify?hash=..."
}

Canonical message:

message = `${hash}|${ts}`  // ASCII

Signing

  • Required: HMAC-SHA256 with secret key.
  • Encoding: Base64URL, no padding.
  • Planned: Ed25519 with public JWKS for detached verify.
  • Rotation: server keys rotate; tuples remain stable.
// Node.js reference
import crypto from "node:crypto";
export function sign(hash, ts, secret){
  const msg = `${hash}|${ts}`;
  const mac = crypto.createHmac("sha256", secret).update(msg).digest();
  // base64url without padding
  return mac.toString("base64").replace(/\+/g,"-").replace(/\//g,"_").replace(/=+$/,"");
}

Validation

// Regex
hash: ^[a-f0-9]{64}$
ts:   ^\d{13}$              // epoch ms
sig:  ^[A-Za-z0-9_-]{43,}$  // Base64URL, no '='

Compare signatures using constant-time equality. Reject any = padding in sig.

JSON schema (v0.1)

{

Reference test vectors

// Input bytes: "hello"
hash = 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
ts   = 1730793600000

Output depends on key. Validate length and Base64URL alphabet only.

Verification

  1. Validate inputs: hash, ts, sig regex.
  2. Recompute expected signature from ASCII hash|ts.
  3. Compare with constant-time equality.
  4. Optionally query verify_url for existence status.
// Pseudocode
ok = timingSafeEqual(sig, b64url(HMAC_SHA256(secret, `${hash}|${ts}`)))

Verify URL

GET https://api.timeproofs.io/api/verify?hash=<SHA256_HEX>
  • Public read. No token.
  • Response: {exists, valid, hash, ts, sig, meta?}.
  • Idempotent: same hash ⇒ same tuple.

Operational policy

  • Algo: HMAC-SHA256 required. Base64URL encoding without padding.
  • Rotation: server key rotation; verification remains stable.
  • Rate limits: strict per IP/token. 429 on excess.
  • Privacy: no original content stored or transmitted.

Conformance checklist (v0.1)

  • SHA-256 → lowercase hex on raw bytes.
  • ts is epoch ms UTC.
  • sig = Base64URL(HMAC-SHA256(ASCII hash|ts)), no padding.
  • Constant-time comparison for signatures.
  • meta has no PII, ≤ ~1 KB recommended.
  • verify_url is publicly reachable.

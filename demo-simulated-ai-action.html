Simulated AI action demo

AI action → Action File → Seal → Verify

This demo simulates an OpenAI-style business action without calling OpenAI or sending raw prompts. It creates a local Action File, hashes it in your browser, requests a Seal for the hash only, and downloads the evidence file.

No OpenAI API callNo raw prompt sentHash-only Seal requestDownloadable .action.json
Demo boundary. This is a simulated action for product demonstration. It proves how the traceability workflow works. It does not prove AI correctness, legal validity, regulatory compliance, or third-party acceptance.

1. Simulated scenario

A customer-ops AI assistant drafts a CRM follow-up action and records an external CRM reference. The raw prompt and generated content are represented by local fingerprints, not stored as readable content.

Input reference

Customer inquiry reference: inquiry_demo_042

Simulated AI action

Draft follow-up and prepare CRM lead update for a sales team.

Target system

CRM demo system, record crm_lead_demo_042.

Stored evidence

Company keeps the Action File and its own CRM/ticket evidence. TimeProofs receives only the canonical payload hash for sealing.

2. Generated evidence

The generated Action File can be downloaded and later verified. If the Seal API is unavailable, the demo still shows the local payload hash and records the failed Seal attempt.

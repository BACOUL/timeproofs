Data flow

Each AgentReady surface has a different data boundary.

The browser and CLI scanners are local-first, while website hosting, npm downloads and GitHub workflow execution involve their respective infrastructure. Planned Pro flows are not active.

Mandatory limitation

TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

TimeProofs AgentReady

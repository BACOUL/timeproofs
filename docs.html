Node.js — verify HMAC

import crypto from "node:crypto";
function verify({ hash, ts, sig }, secret){
  const msg = `${hash}|${ts}`;
  const expect = crypto.createHmac("sha256", secret).update(msg).digest("hex");
  return crypto.timingSafeEqual(Buffer.from(expect,'hex'), Buffer.from(sig,'hex'));
}

🧾 Verify a proof

Use GET /verify?hash=… or POST /verify to validate a proof (hash, timestamp, signature).

Signature: HMAC-SHA256(secret, `${'{'}hash{'}'}|${'{'}ts{'}'}`). UTC clock tolerance ±5 s.

🧰 Status & Errors

  • /api/ping returns HTTP 200 for healthy service.
  • On failures, responses include {"ok":false,"error":"…"} with HTTP 4xx/5xx.
  • Rate limits: verify 60 rpm per IP, timestamp 30 rpm per token.

🛡 Security & Best Practices

  • Send only the 64-char SHA-256 hex. Never upload files.
  • Retry with exponential backoff. Respect rate limits.
  • Store verify_url to simplify audits.
  • Keep client clocks in sync (NTP). Verify signatures server-side for critical flows.

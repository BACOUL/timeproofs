Top scenarios

AI provenance (prompts, outputs)

Hash prompts and outputs locally. Timestamp via API. Share verify URL to prove when content existed and that it is unchanged.

// Client-side hashing
const buf = new TextEncoder().encode(output);
const digest = await crypto.subtle.digest('SHA-256', buf);
const hash = [...new Uint8Array(digest)].map(b=>b.toString(16).padStart(2,'0')).join('');
// Create proof
await fetch('https://api.timeproofs.io/api/timestamp', {
  method:'POST', headers:{'Content-Type':'application/json'},
  body: JSON.stringify({ hash, type:'gen', meta:{ source:'web' } })
});

DevOps & releases

Prove build integrity and release timing across CI/CD.

# CI sample (bash)
HASH=$(sha256sum dist/app.min.js | awk '{print $1}')
curl -s https://api.timeproofs.io/api/timestamp \
  -H 'Content-Type: application/json' \
  -d "{\"hash\":\"$HASH\",\"type\":\"release\",\"meta\":{\"ci\":\"gh-actions\"}}"

What is verified

Project, method and software surfaces.

TimeProofs is the public business name used for this repository and site. AgentReady is the static pre-deployment method for agent-facing OpenAPI and MCP contracts. The current Community implementation is distributed through local browser scanners, an npm CLI package and a GitHub Action.

AgentReady Community is available for free. AgentReady Pro is planned and not purchasable on this site.

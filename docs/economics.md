# Monetization hypotheses, not a launch commitment

Open: public specs, profiles, source SDK, offline verification and free public reference verification. Distribution is developer-led through GitHub, installable source, examples and conformance tests. npm publication is pending, not announced as available.

Proposed managed plans: Developer €49/month, Pro €199/month, Business €799/month, Enterprise custom. Pay for controlled resolution and acquisition, private cases/policies, retention, operational reliability, security and volume. The library itself is not the paid product.

No included case counts or overages are fixed. The cost of signature checks is only one part of service cost. Measure external acquisition calls, retries, retention, storage/egress, tenant isolation, abuse handling, monitoring and support. An external provider may charge more than the engine, and manual evidence collection may break a solo-founder service model.

A quantitative pricing gate needs actual pilots:

- Number of relevant actions per month, artifacts per action, acquisition failure rates.
- Automated coverage and developer integration time.
- Retention size, deletion/backup requirements and support burden.
- Value of preventing an incomplete dossier or reconciling a disputed transaction.
- Explicit willingness to pay for managed orchestration compared with self-host implementation.

Gross margin model: (monthly revenue − host/storage/egress − external collection cost − paid provider usage − direct support) / monthly revenue. Include adverse tail scenarios, not just successful signature checks. No margin estimate is claimed without these measurements.

If the problem can be solved with one existing mandate/receipt verifier and a small script, TimeProofs may be a library rather than a sustainable managed business. If recurring acquisition across independent sources, retained cases and private policies dominate integration cost, managed orchestration may be valuable. This requires evidence from an external developer/customer.

Do not add checkout or subscriptions before these gates are met. Public verification should remain free; costly acquisition can be constrained independently.

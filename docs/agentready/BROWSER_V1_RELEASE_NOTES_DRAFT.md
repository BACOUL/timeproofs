## Release scope

Browser V1 is a static, browser-first readiness scanner for APIs and MCP tools intended to be exposed to AI agents.

It helps developers identify structural risks before giving tools to agents.

Core flow:

```txt
OpenAPI / MCP tools JSON
-> AgentReady scan
-> AgentReady Score
-> risks and recommendations
-> agentready.json
-> static simulation scenario
-> agentready-simulation.json
```

## agentready.json

`agentready.json` is the machine-readable AgentReady contract generated by the scanner.

It describes:

```txt
source type
generated timestamp
score summary
tools or operations
action type
risk level
whether human confirmation is required
detected risks
recommendations
```

## agentready-simulation.json

`agentready-simulation.json` is generated from:

```txt
agentready.json
+ simulation scenario JSON
```

It describes:

```txt
simulation version
source type
scenario count
pass / warning / fail / not_applicable counts
per-scenario findings
mapped AgentReady risks
recommendations
```

## Browser-first privacy and safety model

Browser V1 is intentionally static and local-first.

Must remain true:

```txt
Uploaded files are read in the browser.
Submitted API endpoints are not called.
MCP tools are not executed.
Static simulation does not call APIs.
Static simulation does not execute MCP tools.
Static simulation does not call LLMs.
No backend is required for scanner or simulation flows.
No account is required.
No payment is required.
No dashboard is required.
```

## Limitations

Browser V1 is static analysis only.

It does not prove that an agent will never fail.

It does not replace:

```txt
runtime authorization
runtime monitoring
human review for high-risk actions
security testing
production incident controls
MCP server hardening
API access control
legal review
compliance review
professional security audit
```

# Due Diligence And Transferability

Status: ACTIVE SPECIALIZED SPECIFICATION

Authority: `AGENTREADY_MASTER_PLAN.md`.

## Purpose

AgentReady must remain clean, auditable, transferable, and understandable beyond one person's memory.

This document does not discuss valuation, target buyers, or public resale intent.

## Permanent Discipline

Maintain evidence for:

- domain ownership;
- GitHub ownership;
- npm ownership;
- brand ownership;
- intellectual property chain;
- dependency licenses;
- external contributions;
- architecture decisions;
- ADRs;
- SBOM;
- release provenance;
- incidents;
- metrics;
- revenue;
- churn;
- refunds;
- contracts;
- subprocessors;
- insurance;
- deployment procedures;
- recovery procedures.

## Transferability Rule

Operational knowledge must be documented.

The product must be understandable from:

- repository docs;
- release records;
- tests;
- decision log;
- architecture notes;
- billing/legal records when they exist.

Do not publish confidential data, keys, valuation, or buyer lists.

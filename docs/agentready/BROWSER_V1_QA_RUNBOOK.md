# TimeProofs AgentReady — Browser V1 QA Runbook

## Purpose

This runbook explains how to complete Browser V1 QA in a real browser.

It does not mark Browser V1 as complete. Browser V1 can only be marked complete after `docs/agentready/BROWSER_V1_QA_RESULT.md` is updated to PASS.

## QA modes

```txt
Mode A — Local browser QA
Mode B — Vercel preview QA
```

Mode A is enough for product QA. Mode B is useful when Vercel preview usage is acceptable.

## Mode A — Local browser QA

```bash
git checkout timeproofs
git pull
python3 -m http.server 8080
```

Open:

```txt
http://localhost:8080/
```

Do not use `file://` because browser fixture loading may fail.

Open DevTools:

```txt
Console tab
Network tab
Disable cache while DevTools is open
```

## Mode B — Vercel preview QA

Use the preview URL generated by Vercel.

For preview deployments, confirm they should not be indexed. Do not treat preview SEO status as production SEO status.

## Network tab verification

During all flows, Network should only show static site files, static JSON fixtures, JavaScript, CSS, HTML and static assets.

It should not show calls to uploaded API endpoints, MCP servers, LLM providers, backend API routes, account/session APIs, dashboard APIs or payment providers.

If any live execution or backend requirement appears, Browser V1 must remain blocked.

## Fill the QA result

Update:

```txt
docs/agentready/BROWSER_V1_QA_RESULT.md
```

Use:

```txt
PASS — only if every blocking criterion is satisfied.
FAIL — if a blocking issue is confirmed.
PENDING — if QA is incomplete.
```

Do not mark PASS if:

```txt
Homepage was not checked.
Sample report page was not checked.
Public acquisition pages were not checked.
Exports were not tested.
Network tab was not checked.
Test harness was not run.
Static simulation was not tested.
Mobile/narrow viewport was not at least smoke-tested.
```

## After PASS

Only after Browser V1 QA is PASS:

```txt
2. Consider CLI.

```

## Mandatory limitation text

TimeProofs AgentReady does not guarantee that an AI agent will never fail.

It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

# TimeProofs — Chrome Freeze (V1)

## What it does
A minimal Chrome extension:
- click the TimeProofs icon
- it opens https://timeproofs.io/verify.html

## Install locally
1) Open: chrome://extensions
2) Enable "Developer mode"
3) Click "Load unpacked"
4) Select this folder: browser-extension/chrome-freeze/

## Why this approach
- Zero change to the TimeProofs website
- Zero change to the API
- Zero risk of breaking anything
- Validates the key behavior: "Do users click a Freeze button before sending?"

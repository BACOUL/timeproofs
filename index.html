How it works

One action right before you send. Your email and file tools stay the same.

1

Click Freeze

Select the file (or content) you are about to send. Your original stays on your device.

2

Get a proof file

TimeProofs generates a small proof file (.tproof.json) you keep with your records.

3

Verify anytime

Verification checks integrity against the content. If the content was modified, it will not verify.

Freeze before sending.

If a document matters, freeze it right before you send. Keep the proof file with your records.

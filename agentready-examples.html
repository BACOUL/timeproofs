Good fixture characteristics

  • Clear operation or tool names.
  • Descriptions include when to use and when not to use.
  • Closed string fields use enum.
  • Required input fields are declared.
  • Error responses or tool descriptions help correction.
  • Security or usage boundaries are explicit where possible.

Risky fixture characteristics

  • Financial refund action lacks human confirmation guidance.
  • amount is numeric but unbounded.
  • status or format fields are strings without enum.
  • Customer export exposes sensitive data.
  • Delete operation can be irreversible.
  • Error or tool descriptions are too generic.

TimeProofs AgentReady

Static readiness gate for agent-facing OpenAPI and MCP contracts. TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.

AgentReady Community

Free local static analysis for agent-facing OpenAPI and MCP contracts.

Community is available now. It does not require signup, payment, secrets, a TimeProofs account, hosted scanning or a backend connection for current local and CI usage.

Scan OpenAPIScan MCPUse CI Gate

Currently included

  • OpenAPI scanner
  • MCP tools scanner
  • npm CLI alpha
  • GitHub Action CI gate
  • Markdown and agentready.json outputs

Install

npx @timeproofs/agentready@alpha --help

Use @alpha explicitly for this preliminary release.

Support boundary

No formal support commitments are introduced by Community availability. Current public documentation, examples and repository issues are the available channels.

TimeProofs AgentReady does not guarantee that an AI agent will never fail. It identifies structural risks that may cause AI agents to misuse APIs, tools or MCP servers.
